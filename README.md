# $OUROBOROS — devourer.sol

The serpent eats its own tail — and every other memecoin in the kingdom.

A concept site for an autonomous memecoin liquidation engine: every $BOROS transaction taxes 5% into the Devourer's Wallet, which hunts the open market for rival memecoins, buys them up, and burns them to `0x0`. Forever.
